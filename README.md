One line about office life, under 200 characters. Built for the [The Funniest Office Joke, Judged Head to Head](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c) competition on make.fun.

## The joke

> I replied-all to say please stop replying-all, and now the thread has its own meeting invite.

93 characters, one line. The reply-all loop turns twice: first the reply-all used to protest reply-all itself, then the thread escalating beyond email into its own meeting invite.

## Run it

```sh
node main.ts
```

Node 22 or later. No dependencies, no network. The program writes the joke to `/output/entry.txt` (created if needed).
